# 浙大智能设计 · 设计系统 1.0

独立适配 ego(lite) 的视觉与页面结构，不是其官方组件库，也不代表浙江大学官方品牌规范。仅本地预览。

## 页面体系

全局导航：首页 / 精品慕课 / 优秀作品。首页采用品牌叙事与重点内容；精品慕课采用 Articles 的大标题、胶囊筛选及三列插画卡片；课程内页采用 Docs 的章节导航、教学正文、节内目录；作品展示沿用大幅真实作品图。章节侧栏仅存在于课程内部。

## 变量与排版

tokens.css 是本预览唯一色彩变量源。深蓝 #172454、标题蓝 #254b98、浅灰 #f3f3f1。亮蓝用于视觉强调，正文链接使用较深的 #1464cc；正文 #62666e。正文 17–18 px / 1.8，辅助文字至少 14 px。中文标题 42–88 px，保持自然字距。间距使用 4/8/12/16/24/32/48/64/96 px。

## 组件约定

按钮：主行动使用深蓝到亮蓝渐变，次行动使用细边框；悬停变色、按下保留清晰反馈、禁用不可触发。键盘焦点使用 3 px 外描边，不能删除。筛选为 button + aria-pressed，不冒充切换面板。卡片只有可进入真实内容时才整卡链接；方向视觉样张不假装课程。表单后续应包含标签、错误文本、等待及成功反馈，未实现的组件不可声称已完成。

课程卡片：3/2/1 列按可用宽度调整，封面统一 3:2。标题、简介、教师、学分与学期使用真实数据；缺失不编造。简介最多三行，元信息底部对齐。课程列表的筛选与滚动位置在正式路由中应保留。

视频：16:9，圆角 20 px，禁止自动播放；接入既有视频源时保留播放、音量、全屏及字幕能力。当前为明确标注的占位，不是实际播放器。嵌入失败需提供原视频入口；教学内容和练习不依赖播放成功。

学习页：桌面三栏，正文优先；中屏移除右目录，小屏将章节收起为目录控件。当前预览小屏展示简短章节链接；正式长目录需使用 details 或抽屉。标题锚点避开固定导航。禁止虚构进度、成绩、完课数。

## 插画

统一色彩、材质、画幅与视觉重心，按内容分别构图。技术基础表达数据/模型/评价；交互研究表达人/情境/反馈；硬件表达感知/结构/行动。当前 CSS 仅构图样张，非最终原创插画。封面不烘焙课程标题；真实学生作品不替换为生成图片。

## 动效与无障碍

常规反馈 220 ms，缓动 cubic-bezier(.32,.72,0,1)，位移不超过 5 px。尊重 prefers-reduced-motion。视频不自动播放。所有互动可键盘到达；状态使用 role=status，选中状态同时用文字/属性表达。大面积渐变用于品牌区，不覆盖正文。

## 实现状态

已实现：变量、响应式展示、课程过滤、锚点导航、展开组件、禁用与反馈状态。未接入：真实视频源、账号、学习记录与正式课程路由。没有发布到 ChatGPT Sites，也未覆盖原首页。

### 主按钮状态修订

按用户提供的两张参考图：默认态为平整的横向渐变，深蓝区域约占 63%，右端过渡亮蓝，文字浅蓝。悬停态增加浅蓝细轮廓及内侧柔光，不上浮。按下时略暗并收敛光效；键盘焦点另外使用外描边，避免只靠柔光表达焦点。
